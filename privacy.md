# Privacy policy

Last updated: 28 October 2026

This policy covers YT Shorts Automation, a private tool used by the Innovatio YouTube channel.

## What the tool does

It uploads and schedules videos made by Innovatio on Innovatio's own YouTube channel, using the YouTube Data API with permission to upload videos. Only the channel's owner uses it. It isn't offered to the public, and nobody else signs in to it.

## Data it uses

When the owner signs in, Google gives the tool a sign-in token for the owner's own channel. The token is stored privately and used only to upload and schedule the channel's videos. The tool doesn't read, collect or store any other Google account data, and it collects no data from viewers or anyone else.

## Sharing

No data is sold or shared. Videos are sent only to YouTube.

## YouTube

The tool uses YouTube API Services. The [YouTube Terms of Service](https://www.youtube.com/t/terms) and the [Google Privacy Policy](https://policies.google.com/privacy) apply to anything on YouTube.

## Removing access

The owner can remove the tool's access at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).
